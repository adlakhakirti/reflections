# Interpretation rubric

For each dimension use SUPPORTED, CONCERN, or INSUFFICIENT INFORMATION. Cite passage IDs and explain. These are reviewer judgments, not calibrated measurements.

1. Context: does the reading account for preceding requests and situational constraints?
2. Scope: does a local observation become an unsupported enduring trait, intention, feeling, or causal claim?
3. Counterevidence: are exceptions represented proportionately? Is a search miss being interpreted as absence?
4. Recurrence: are sessions distinct, participant diversity considered, and denominators/time windows stated where relevant? No universal minimum is supplied.
5. Revision: did missing old context cause a correction, or did later observations justify a time-bounded update? Different participant mix can confound change. If no prior claim, NOT TESTED.
6. Abstention: should a claim be withheld for thin, missing, or ambiguous evidence? Empty output alone does not prove appropriate abstention.
7. Whole view: does selection create an unfair overall picture? Are user feedback and evidence truth being conflated?

Actions: retain (supported within its stated scope); qualify (add context/limits); revise (change an interpretation or time-bounded pattern); withdraw (remove an unsupported existing claim); withhold (do not create a claim); needs-human-review (ambiguity cannot be resolved from provided evidence).

Do not predict coaching outcomes, label a person, or certify launch readiness. Report limited samples and AI-authored labels openly. For later human review, keep independent ratings and reasons before resolving disagreements. Do not report agreement without actual independent labels and a defined scoring unit.
